# Start here

Tibeb is one window for making short vertical videos on your Mac. An AI agent you already pay for (Claude Code or
Codex) does the building; Tibeb gives it the tools, the house rules and a place to see the result.

## The five-minute version

1. Open **Setup**. Every line should have a tick. One signed-in agent is enough.
2. Open **Projects**, create one, and drop in what the video is about: logos, screenshots, photos, clips, notes.
3. Open **Make**. Choose the agent and the project, pick a starting point, fill in the [brackets], press **Make the video**.
4. Watch the log on the right. A video usually takes 10 to 25 minutes. It plays above the log when it is done.
5. Not right yet? Type notes the way you would to an editor ("the title comes in late") and send them.
6. Open **Deliver** to check loudness and shape before posting.

## What each screen is for

| Screen | Use it to |
|---|---|
| Make | Prompt a whole video and watch it being built |
| Projects | Keep one folder per video and add material |
| Library | Find free sounds, music, textures and typefaces made on this Mac |
| Create | Fill in a template by hand (titles, maps, story scenes) |
| Edit | Move, trim and retime clips on a timeline, with Claude docked beside it |
| Record | Record your screen or camera through OBS into a project |
| Assistant | Ask questions about a project without running commands |
| Deliver | Check an export before posting |
| Guides | Read these pages and copy prompts |
| Setup | See what is installed and fix what is missing |

## Good to know

- Everything is a plain file in the workspace folder (shown at the bottom of Setup). Nothing is locked inside the app.
- The agent runs on your own Claude or ChatGPT plan. Long videos use a lot of it.
- Paid tools (Higgsfield, ElevenLabs and the like) are switched off for Make runs.
