# Style rules (template)

The `cutroom` skill reads `style.md` next to it at the start of every video. Copy this file to `style.md` and keep it
current: add a dated line whenever you confirm or reject something, so your taste builds up instead of starting over.

## Always
- Shape and count: for example, one vertical 9:16 video per request.
- Credit line, if you use one.

## Look
- What you loved (with the video it came from).
- What you rejected, in your own words.

## Pace and voice
- For example: no added pauses between scenes; trim long silences to about a quarter second.

## Sound
- For example: no music unless a track is clearly good; when several like things appear in a row, one simple click, the same each time.

## Captions and text
- For example: at most two typefaces; highlight only the word that carries the line.

## Things never to use again
- Components or effects you disliked, named plainly.
